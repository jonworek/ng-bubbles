# Provenance and distribution review

Reviewed for the initial public release, 0.2.0, on 2026-10-16.

## Application and protocol

The Electron main process, REST/Socket.IO adapter, messaging state management,
HTML/CSS renderer, preload bridge, and tests were written for this project.
No Flutter/Dart client, hosted web build, upstream server implementation,
or upstream branding assets are bundled.

BlueBubbles documentation and source were consulted to understand request and
response shapes, socket events, unread-message queries, contact-image fields,
group icons, attachments, and Private API requirements. This is **not a
clean-room implementation** and is not described as one. Protocol identifiers
such as endpoint names and event/field names appear for interoperability.

Reference snapshots consulted during development:

- BlueBubbles server: `f2e2286241a7c3b6617a82b37d4afaab4df3a6b9`
  https://github.com/BlueBubblesApp/bluebubbles-server/tree/f2e2286241a7c3b6617a82b37d4afaab4df3a6b9
- BlueBubbles client: `512eb185fc931097ca5dddd7945b30f6ef960b9f`
  https://github.com/BlueBubblesApp/bluebubbles-app/tree/512eb185fc931097ca5dddd7945b30f6ef960b9f

Both reference checkouts carried Apache-2.0 license files. The audit compared
application source against those checkouts and found no identical nontrivial
source lines longer than 35 characters. That check supports the code review;
it is not proof of independent authorship or a legal clearance opinion.

## Assets and data

The current N speech-bubble icon and unread variant are generated by
`scripts/generate-assets.py`, authored for this project. No upstream logo is
used. Test JPEG/TIFF/HEIC portraits are synthetic, generated for testing; they
are not photographs of users or copied upstream test samples. Test contacts,
addresses, messages, and passwords are fictional. Public source and release
previews contain no personal server configuration or user conversations.

## Third-party code

Application code/original assets are MIT licensed. Runtime npm dependencies
remain separate, unmodified modules with their notices intact. The generated
THIRD_PARTY_NOTICES.md records all installed production dependencies, versions,
license declarations, and supplied license texts. Electron and Chromium ship
their own notices in the installation directory. Build tools retain their own
licenses and are installed using the lockfile, not vendored into app source.

HEIC decoding uses heic-decode 2.1.0 (ISC) and libheif-js 1.23.5 (LGPL-3.0).
The latter contains compiled libheif and libde265 code. The binary distribution
includes GPL/LGPL texts, complete matching library sources and build recipes,
immutable source hashes, and instructions for rebuilding with modified
libraries. Source archives retain their own copyright/license notices;
upstream build scripts may have GPL terms distinct from the library terms.
This project's MIT license does not relicense those third-party works.

The published heic-decode package declares ISC in package.json but does not
supply a separate license file. Its declared license/author are recorded and
the canonical ISC text is included; this packaging limitation is disclosed
rather than inventing an upstream notice.

## Naming and limits

The public name is Not Green Bubbles. References to BlueBubbles, Apple, and
iMessage identify compatible services and do not imply endorsement. Legacy
internal IDs/data paths remain for migration compatibility. A naming search
is not a trademark registration/clearance search. Names generally raise
trademark questions rather than copyright questions; no claim of exclusive
rights to upstream names is made.

that every jurisdiction or possible claim has been resolved. Any new copied
