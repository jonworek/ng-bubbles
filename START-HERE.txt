NG Bubbles 0.4.3 — native Windows client for BlueBubbles servers
NG means Not Green.

1. Quit the previous app from its system tray menu.
2. Run NG-Bubbles-0.4.3-x64-Setup.exe.
3. Launch NG Bubbles. Re-enter the server password if requested.

Native C# / .NET 10 / WinUI 3. Windows 10 2004+ or Windows 11, x64.
The portable ZIP must be extracted with all files before starting NG Bubbles.exe.

Old settings/history/photos are imported. Old browser drafts remain in the old app;
finish or copy them before uninstalling it. Original data is not removed.
The rename may require pinning the tray icon once more.
HEIC previews may require Windows HEIF/HEVC image extensions.

Settings > Diagnostics, or Ctrl+Shift+D, opens technical diagnostics.
Close keeps the app running in the tray; Ctrl+Q quits.
